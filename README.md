# git hub
## iturmで打つやつ
git pull origin main　現状最新のブランチをダウンロード
git checkout -b 20260515 新しいブランチを作る　20260515任意
　※git checkout ブランチ名を入れないでエンターすると差分が消える
git status 今どのブランチにいて差分がどれだけあるかを確認
git add 修正したファイルを追加　
. は差分のあるファイル全てをあげる（プロジェクトルートにいる必要がある）　
git commit -m どういう変更内容になるのかのコメント
git log コミット履歴を見れる
git push origin 任意でつけた名前　gitにアップロード
git branch ブランチの確認
